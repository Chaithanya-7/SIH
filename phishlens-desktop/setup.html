PhishLens console is not reachable

The desktop application is a shell around the PhishLens SOC console. It needs the PhishLens backend and dashboard running before it can display anything. From the repository root:

start-all.bat

Or start each service directly:

cd phishlens-backend && node server.js cd phishlens-dashboard && npx vite --port 3005

Close and reopen PhishLens once those are running.
